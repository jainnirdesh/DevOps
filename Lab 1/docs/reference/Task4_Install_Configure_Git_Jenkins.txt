Step 1 — Install Git
The package index is refreshed and Git is installed from the Ubuntu repositories.
sudo apt update
sudo apt install -y git
Step 2 — Verify the installation
The installed version is confirmed with:
git --version
Output: git version 2.53.0
Step 3 — Set the global Git configuration
The identity used to author commits is set globally, along with the default branch name for new repositories.
git config --global user.name "Yatharth Chopra"
git config --global user.email "yc9891966@gmail.com"
git config --global init.defaultBranch main
Step 4 — Verify the configuration
git config --global --list
Output:
user.name=Yatharth Chopra
user.email=yc9891966@gmail.com
init.defaultbranch=main

Jenkins Installation
Jenkins was installed from the official Jenkins LTS apt repository. Java 21 (OpenJDK) was installed first as a prerequisite.
sudo apt install -y fontconfig openjdk-21-jre
 
curl -fsSL https://pkg.jenkins.io/debian-stable/jenkins.io-2026.key \
  | sudo tee /usr/share/keyrings/jenkins-keyring.asc > /dev/null
 
echo "deb [signed-by=/usr/share/keyrings/jenkins-keyring.asc]" \
  "https://pkg.jenkins.io/debian-stable binary/" \
  | sudo tee /etc/apt/sources.list.d/jenkins.list > /dev/null
 
sudo apt update
sudo apt install -y jenkins
sudo systemctl enable --now jenkins
sudo systemctl status jenkins --no-pager
Note: the Jenkins project rotated its Linux repository signing keys, so the current 2026 key is required. Using the older 2023 key produces a NO_PUBKEY 7198F4B714ABFC68 error and the jenkins package cannot be located.
