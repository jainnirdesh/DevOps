Lab 1 — Task 7: Jenkinsfile Defining Pipeline Stages
Yatharth Chopra  |  Jenkins 2.568.2  |  Job: devops-lab1-pipeline
Objective
Create a Jenkinsfile defining pipeline stages (build, test, deploy) and demonstrate a declarative pipeline execution.
Step 1 — Write the Jenkinsfile
A declarative Jenkinsfile was created at the root of the repository. It defines three stages executed in sequence, plus a post block that reports the overall outcome. Declarative syntax is used, identified by the top-level pipeline block.
pipeline {
    agent any
 
    stages {
        stage('Build') {
            steps {
                echo 'Building application...'
                sh 'python3 --version'
                sh 'python3 -m py_compile app.py'
                echo 'Build stage complete'
            }
        }
 
        stage('Test') {
            steps {
                echo 'Running unit tests...'
                sh 'python3 -m unittest test_app.py -v'
            }
        }
 
        stage('Deploy') {
            steps {
                echo 'Deploying application...'
                sh 'mkdir -p /tmp/deploy && cp app.py /tmp/deploy/'
                sh 'python3 /tmp/deploy/app.py'
                echo 'Deployed successfully'
            }
        }
    }
 
    post {
        success { echo 'Pipeline completed successfully' }
        failure { echo 'Pipeline failed' }
    }
}
Stage responsibilities
Build — verifies the Python environment and compiles app.py to bytecode, failing the pipeline immediately on any syntax error.
Test — runs the unit test suite in verbose mode. A failing assertion aborts the pipeline before deployment.
Deploy — copies the verified application to the deployment directory and executes it there to confirm the deployed artifact runs.
Step 2 — Commit the Jenkinsfile to version control
Keeping the Jenkinsfile in the repository means the pipeline definition is versioned alongside the application code (pipeline as code).
cd ~/devops-lab1
git add Jenkinsfile
git commit -m "Add declarative Jenkinsfile with build, test and deploy stages"
git push
Step 3 — Create the Pipeline job
A new job of type Pipeline named devops-lab1-pipeline was created. Rather than pasting the script into Jenkins, the definition is set to Pipeline script from SCM so that Jenkins reads the Jenkinsfile from the GitHub repository on every build.
Definition       : Pipeline script from SCM
SCM              : Git
Repository URL   : https://github.com/yatharthchopra2424/devops-lab1.git
Branch Specifier : */main
Script Path      : Jenkinsfile
